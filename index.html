Old Hattrick kits, back in use

Drop a .kd3 file from the old kit designer and get a JSON file in the new designer's format. The conversion runs in your browser, so your files are never uploaded.

This browser can't unpack .kd3 files. Open the page in a current version of Chrome, Edge, Firefox or Safari.

    How close is the result?

    Positions, sizes, colors, text and gradients all carry over. For one kit the new designer converted itself, every shape matched. On other kits the shading can look a little stronger than it did in the old designer.

    The old format has no room for images, so crests and logos that were bitmaps are not included. Player numbers drawn by the game are not part of the file either.
